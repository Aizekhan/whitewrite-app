**Деплой:** `bec4ef6` — посилений контроль діалогів через імператив + дублювання в кінці

---

## 📋 План тесту

1. Створити **два ідентичні проєкти** з різним `dialogue`:
   - Проєкт A: `dialogue = 0` (БЕЗ діалогів)
   - Проєкт B: `dialogue = 100` (майже цілком діалоги)

2. Згенерувати **одну сцену** в кожному з однаковим:
   - `title`: "Зустріч"
   - `desc`: "Два давні друзі зустрічаються після років розлуки в старому кафе."
   - `sceneIntent`: "conflict" (конфлікт — щоб мати підстави для діалогу)
   - `length`: 700 слів

3. Порівняти результати:
   - **Проєкт A (0%):** має бути pure narrative, жодної прямої мови
   - **Проєкт B (100%):** має бути screenplay-style, майже лише репліки

## ✅ Очікуваний результат

### Проєкт A (dialogue = 0%):
```
Коли Марко увійшов у кафе, він одразу побачив Олега...
Він пригадав, як вони востаннє бачилися...
Напруга між ними була відчутною...
```
**Жодних лапок, жодної прямої мови.**

### Проєкт B (dialogue = 100%):
```
— Марко? — Олег підвівся з-за столика.

— Так, це я. — Марко нерішуче підійшов.

Пауза затягнулася.

— Ти... змінився, — нарешті сказав Олег.

— І ти теж. — Марко сів навпроти.
```
**Майже лише репліки, мінімум опису.**

---

## 🎯 Метрика успіху

- **0%:** В тексті сцени немає символів `«»` або `""` (цитати/діалоги)
- **100%:** >80% рядків містять репліки (рахувати рядки з `—` або `«`)

Якщо різниця **очевидна візуально** → тест пройдено ✅

Якщо обидві сцени виглядають однаково → потрібні жорсткіші методи (system prompt, retry logic)

## 🔧 Якщо тест НЕ пройдено

Можливі причини:
1. **Scene Intent перевершує dialogue control** — "conflict" природно генерує діалоги
   - Fix: Тестувати на "worldbuilding" (світобудова) замість conflict
2. **Canon context занадто великий** — тоне сигнал
   - Fix: Тестувати на порожньому каноні (перша сцена)
3. **Model не слухається** — Claude/Gemini ігнорує інструкції
   - Fix: System prompt або temperature=0 для жорсткого контролю
