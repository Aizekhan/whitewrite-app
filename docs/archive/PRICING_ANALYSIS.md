# WhiteWrite — Аналіз ціноутворення та планів

## 📊 Фактичні витрати на AI (станом на січень 2025)

### Claude 3.5 Sonnet (Anthropic)
**Модель:** `claude-3-5-sonnet-20240620`
- **Input:** $3.00 / 1M tokens
- **Output:** $15.00 / 1M tokens

**Реальне використання в WhiteWrite:**
- Середня сцена: ~700 слів української прози
- Input (prompt): ~1,500-2,000 tokens (canon + попередні сцени + інструкції)
- Output (сцена): ~1,200-1,500 tokens (українська займає більше токенів)
- **Max output:** 4,096 tokens per request

**Вартість однієї сцени (середня):**
- Input: 1,750 tokens × $3.00 / 1M = $0.00525
- Output: 1,350 tokens × $15.00 / 1M = $0.02025
- **Разом: ~$0.0255 (~$0.025 за сцену)**

### Gemini 2.5 Flash (Google)
**Модель:** `gemini-2.5-flash`
- **Input:** $0.075 / 1M tokens (до 128k context)
- **Output:** $0.30 / 1M tokens

**Реальне використання в WhiteWrite:**
- Такі ж параметри як Claude (700 слів, 4096 max)
- Input: ~1,750 tokens
- Output: ~1,350 tokens

**Вартість однієї сцени:**
- Input: 1,750 × $0.075 / 1M = $0.00013
- Output: 1,350 × $0.30 / 1M = $0.00041
- **Разом: ~$0.00054 (~$0.0005 за сцену)**

**Різниця:** Claude **в 50 разів дорожче** Gemini!

### ⚠️ Проблема з Worldforge:
- Користувач платить $29/міс

- Вартість: 320 × $0.025 = **$8 на AI**
- Але якщо користувач активно використовує (50 сцен/міс):
  - 50 × $0.025 = $1.25/міс на AI

- 300 × $0.025 = **$7.50/міс на AI**
- Маржа: $21.50 ✅ Все ще ок

**Реальна загроза:** 8,000 "токенів" в UI != API tokens. Це абстрактна метрика.

## 🧮 Економіка сценаріїв використання

### Типовий автор (хоббі)
- Пише 1-2 сцени на день
- 50 сцен/міс
- **Ідеальний план:** Creator ($9) — 100 сцен Gemini
- Витрати на AI: $0.025 → Маржа: $8.975

### Активний письменник
- Пише 5-10 сцен на день
- 200 сцен/міс
- **Ідеальний план:** Author ($19) — 300 сцен Gemini
- Витрати: $0.10 → Маржа: $18.90

### Професіонал (якість важлива)
- Пише 3-5 сцен на день, але хоче топову якість
- 100 сцен/міс Claude
- **Ідеальний план:** Pro ($49) — 200 сцен Claude
- Витрати: $2.50 → Маржа: $46.50

### Power user (ризик)
- Генерує 20 сцен/день Claude
- 600 сцен/міс
- Витрати: $15 на AI
- **Проблема:** якщо план $49 → втрачаємо гроші!

**Рішення:** Rate limiting або soft cap:
- Після 200 сцен → slower processing
- Або: додаткові сцени $0.10/шт
