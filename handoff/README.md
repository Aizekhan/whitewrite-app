## Повний інвентар функціоналу (кожне має працювати в проді)
**Вхід / акаунт**
- Стартовий екран мага → форма створення; модалка входу/реєстрації; гейт «Проекти» без входу; вихід; токени + аватар знизу-зліва наскрізно.

**Створення історії** (`flow.jsx`)
- Назва · опис · режим Guided/Auto · обсяг(+к-ть серій) · фінал(+свій) · жанри(до 4) · довжина сцен · **повзунок діалогів (авто за жанром)**.
- Анімація мага → blur-перехід у книгу.

**Книга** (`book.jsx`, `pages.jsx`, `book-edit.jsx`, `book-related.jsx`)
- Перегортання (кутові стрілки + віконні кружечки з номерами), **пагінація тексту по аркушах**, перемикач сцени/акта, персистентність позиції.
- **Редагування** (кнопка-олівець, світиться): Хранитель пропонує нові сутності (тип) + конфлікти → canon; зберігає та реформатує по аркушах.
- **Scene Intent** «Що далі?» (7 напрямів + свій опис) → наступна сцена.
- Закладки канону; панель шрифту (Aa).

**Всесвіт** (`wt-*`)
- Дерево (Хроніка-серце + 5 категорій); **Хроніка** з мінімальним редагуванням (премиса/опис/закони).
- Воркспейс категорії: пошук/фільтр/сорт/групи; види **Картки·Список·Граф**; профіль + клікабельні звʼязки; перемикач категорії + **сцена-лінза**.
- Картки: редагування інфо (не лише фото) + обмеження (обсяг ≥ написаних сцен) + видалення з підтвердженням.
- **Reconstruction overlay**: тип зміни → стратегія → план → виконання.
- Заглушки `ph-{type}.png` коли нема зображення.

**Режисер** (`ws-*`)
- Розрахувати к-ть кадрів; додати/редагувати/видалити кадр; **намалювати** + варіанти(3-5); заглушка `ph-shot.jpg`.
- **Діалоги в кадрі**: кілька реплік (хто·емоція·текст), оцінка тривалості озвучки.
- **Візуальний канон + LoRA**: набір референсів (генерувати+підтвердити / завантажити / видалити), пороги 3/15/20.

**Решта**
- Маркетплейс (читати/оцінювати) · Акаунт (профіль·аватар·плани[Gemini/Claude]·токени) · Замовити книгу (бета «скоро») · **База знань** (`kb.js`, пошук·категорії·читалка, 22 статті).

## Критерій готовності
Прод вважається ідентичним, коли **кожен пункт інвентарю вище** працює й виглядає
як у прототипі. Порт — по одному екрану; не переходити далі, поки кнопки екрана
не працюють і вигляд не збігається пліч-о-пліч.

## Як працювати з прототипом
Файли прототипу — у цьому ж репозиторії дизайну (відкрий через GitHub або попроси
експортувати). HTML-точки входу: `White.html` (повний застосунок), і три стовпи
окремо. JSX вантажиться через in-browser Babel — у проді прекомпіляція.
